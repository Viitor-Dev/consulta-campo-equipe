# Consulta de campo

Interface estática para celular, com conteúdo criptografado antes da publicação.

- Hospedagem: GitHub Pages; não exige conta do visitante.
- Agenda e aplicativo: AES-256-GCM, PBKDF2/SHA-256 e senha aleatória entregue separadamente.
- A senha e os dados originais não integram este repositório.
- Anotações e backups: criptografados no dispositivo. Não há sincronização nem envio de formulários para servidor.
- Relatórios HTML/CSV exportados são legíveis e devem ser compartilhados somente com destinatários autorizados.
- O navegador desbloqueado tem acesso aos dados; use Bloquear consulta ao terminar.
- Alterações maliciosas no site ou um aparelho comprometido podem expor a senha e os dados. Esta solução não substitui um serviço com controle de acesso no servidor.
- Uma cópia criptografada publicada pode continuar existindo após a remoção do site. Guarde a senha fora do GitHub.

## Publicação

Configurar Pages para a branch main, pasta raiz. Não subir outros arquivos, planilhas, relatórios ou senhas. Usar HTTPS.
